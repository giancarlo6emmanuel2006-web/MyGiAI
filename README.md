# MyGiAI - Asistente Virtual Académico

Aplicación web hecha con Python y Streamlit para apoyar el estudio de Investigación de Operaciones.

## Módulos

- Chat académico que detecta y resuelve modelos lineales escritos en texto
- Modelación de programas lineales
- Programación lineal con comprobación de restricciones
- Método gráfico con región factible y vértices
- Método Simplex paso a paso
- Transporte y Asignación (algoritmo húngaro)
- Inventarios EOQ y punto de reorden
- Ejercicios de práctica con generador aleatorio y autocorrección

## Tecnologías

Python, Streamlit, NumPy, SciPy, Matplotlib

## Cómo ejecutarlo

    pip install -r requirements.txt
    streamlit run IO_MyGiAI.py
